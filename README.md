# Selfunnel Add-ons

Собственный репозиторий аддонов [selfunnel.ru](https://selfunnel.ru) для Home Assistant (HA Add-on Store).

## Selfunnel Tunnel

Удалённый доступ к Home Assistant по адресу `https://<поддомен>.selfunnel.ru` — без проброса портов, из-за CGNAT/серого IP. Трафик идёт через исходящее TLS-соединение с сервером selfunnel.

## Сценарии

| Тариф | Что включено |
|---|---|
| **Умный дом** (100 ₽/мес) | 1 туннель HTTP/HTTPS под аддон, промокоды работают |
| Lite (170 ₽/мес) | 1 соединение |
| Pro (390 ₽/мес) | 10 соединений + свои домены |

## Установка

1. Home Assistant → **Настройки → Дополнения (Add-ons) → Магазин аддонов**.
2. Меню (⋮) справа сверху → **Репозитории**.
3. Вставьте `https://github.com/esacer1989/selfunnel-addons` → **Добавить**.
   > Репозиторий приватный: на время теста работает только для владельца (GitHub token / invite). Для публичной установки — архивировать репо.
4. Обновить список → в поиске появится **Selfunnel Tunnel** → **Установить**.
5. **Конфигурация** аддона: `install_token` (ЛК selfunnel → «Установщик» → «Показать install-токен») и при желании `subdomain`.
6. **Запустить** и проверить `https://<поддомен>.selfunnel.ru`.

## Диагностика

Ситуации из лога аддона:

| Сообщение | Что делать |
|---|---|
| «install_token недействителен» | Скопируй токен из ЛК заново (без пробелов/переносов) |
| «Недопустимый поддомен» | Только `a-z0-9-` (буквы/цифры/дефис, ≤40 символов) |
| «Недопустимый local_host» | Имя хоста/IP — только буквы, цифры, точка, дефис |
| «local_port должен быть числом…» | Порт — от 1 до 65535 |
| «selfunnel недоступен … повтор» | Проверь интернет; аддон сам делает 5 повторов |
| Туннель не открывается снаружи | Проверь `local_port` (обычно 8123) и что туннель запущен в ЛК |

## Что делает аддон изнутри

1. Читает `install_token` из `/data/options.json` (обход bashio::config, работающий на HA 2026.9.x).
2. POST `https://selfunnel.ru/api/addon/validate` — сверяет токен, забирает **frp_token** и резервированный **subdomain**.
3. Генерирует `/data/frpc.toml` (chmod 600) с TLS и `loginFailExit = false`.
4. Запускает `frpc` (0.71.0 из официального релиза fatedier/frp, sha256 проверен при сборке).

Наружу ничего не открывается: у аддона нет ни портов, ни host-network, ни привилегий. `subdomain`, `local_host`, `local_port` нормализуются регэкспами — TOML-конфиг нельзя исказить перепутанным полем.

## Требования

- Home Assistant с Supervisor (HAOS / HA Virtual Machine).
- ЛК selfunnel с четвертым тарифом **«Умный дом»** (или любой другой каталог) и активным туннелем.

## Структура репо

```
repository.json      # манифест репозитория (HA Add-on Store)
selfunnel/           # аддон «Selfunnel Tunnel» (v1.1.0)
  config.yaml        # описание/схема опций
  Dockerfile         # сборка frpc 0.71.0 (sha256-гейт для amd64/aarch64)
  build.yaml         # образы сборки (AMD64/ARM64)
  run.sh             # runtime: validate → frpc.toml → frpc
  icon.png / logo.png / DOCS.md
assets/logo-tile.svg # исходник логотипа
```
