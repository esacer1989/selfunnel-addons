# Туннель selfunnel для Home Assistant

Публикует ваш Home Assistant по адресу `https://<поддомен>.selfunnel.ru` — без проброса портов на роутере. Весь трафик идёт через исходящее TLS-соединение с нашим сервером.

## Что понадобится

1. **install-токен** из кабинета selfunnel: ЛК → «Установщик» → кнопка **«Показать install-токен»**. Это единственное, что вводится в настройках аддона (лучшая безопасность — токен не хранится нигде в логах).
   > Поля «frp_token» на этапе v1 не существует: фрп-токен приходит автоматически в ответе сервера.
2. Активный туннель в кабинете (или мы предложим автоматически созданный поддомен — токен используется для его резервирования).

## Установка

1. Home Assistant → **Настройки → Add-ons → Add-on Store**.
2. Меню (⋮) справа сверху → **Репозитории**.
3. Вставьте: `https://github.com/esacer1989/selfunnel-addons` → **Добавить → Обновить**.
4. В списке появится **Selfunnel Tunnel** → **Установка**.
5. В карточке аддона → **Конфигурация** → вставьте **install_token** → **Сохранить**.
6. **Запустить**. Через 10–20 секунд откройте:
   `https://<ваш-поддомен>.selfunnel.ru`

## Диагностика

Логи аддона → вкладка «Лог». Типовые ситуации:

| В логе | Что делать |
|---|---|
| «install_token недействителен» | Скопируйте токен из ЛК заново, без пробелов |
| «Нет поддомена» | Создайте туннель в кабинете → перезапустите аддон |
| «selfunnel недоступен … повтор» | Проверьте интернет во HA; аддон сам повторяет 5 раз |
| Туннель не открывается снаружи | Остановите/запустите аддон, проверьте, что `local_port` = порт вашего HA (обычно 8123) |

## Как это работает

`frpc` внутри аддона подключается к серверу selfunnel (порт 7000, TLS) и пробрасывает ваш Home Assistant (`homeassistant:8123` внутри docker-сети HA) на `https://...selfunnel.ru`. Наружу ничего не открыто: у аддона нет ни портов, ни host-network, ни привилегий.
